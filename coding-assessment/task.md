# Coding Assessment

## Tasks Overview
There are 2 tasks, so you may choose **one** of the following two tasks in this coding assessment.

 - Task 1 - Authentication Workflow (Difficulty: Medium)
 - Task 2 - MongoDB Connection & Communication Workflow (Difficulty: High)

## Overview

This assessment evaluates your ability to:

- Understand and structure a technical problem.
- Define clear requirements and implementation direction.
- Communicate effectively with an AI coding agent.
- Use AI tools efficiently through precise instructions.
- Make appropriate technical and architectural decisions.
- Review and validate AI-generated work within a limited timeframe.

You may use an AI coding agent during this assessment.

You must provide the technical direction, requirements, scope, and implementation
decisions. The AI agent should be treated as an execution assistant rather than
the primary source of the solution.

## Time Limit

**15 minutes**

# Task 1 — Authentication Workflow

### Objective

Design and implement an authentication workflow that makes the authentication
experience more engaging and less conventional than a typical:

> Login → Enter credentials → Submit

Many modern websites attempt to make authentication feel more attractive,
interactive, and enjoyable rather than treating it purely as a technical
barrier.

Create a structured authentication workflow that demonstrates this concept.

### Requirements

The implementation should demonstrate:

- A clear authentication flow.
- An intentional user experience.
- Appropriate authentication states.
- Reasonable handling of authentication errors.
- A structure that can be extended for a real application.

The specific authentication experience, interaction model, structure, and
implementation approach are intentionally left open.

Your solution should demonstrate your own technical and creative direction.

#### Implement this task on branch task/authflow.

# Task 2 — MongoDB Connection & Communication Workflow

### Objective

Build a safe and flexible MongoDB connection system and establish a workflow
that supports communication between the application, REST APIs, sockets, and
MongoDB.

### Requirements

The implementation should demonstrate:

- A structured MongoDB connection system.
- Safe connection and configuration handling.
- A flexible structure that can support application growth.
- REST API communication with MongoDB.
- Socket-based communication involving MongoDB-backed application data.
- Appropriate separation of responsibilities between the database,
  application logic, REST API, and socket communication.

The specific architecture and implementation approach are intentionally left
open.

Your solution should demonstrate your own technical judgment and ability to
define an appropriate workflow.

#### Implement this task on branch task/mongodb.

# AI Tool Usage

AI coding tools are allowed and expected to be used during this assessment.

The assessment is not intended to measure how much code you can manually type.

Instead, it evaluates how effectively you can use an AI coding agent through
your own technical knowledge, direction, requirements, and decisions.

You are responsible for:

- Defining the task scope.
- Providing technical requirements.
- Giving implementation direction.
- Controlling the AI agent's scope.
- Reviewing the generated implementation.
- Identifying and correcting problems.
- Making final technical decisions.

Avoid relying on the AI agent to independently define the entire solution.

The quality of the result should reflect your ability to direct and utilize
the AI tool effectively.

# Final Report

At the end of the 15-minute assessment, provide a short professional report.

## Report Format

### 1. AI Agent Commands / Prompts

List the commands, prompts, and instructions you used to direct the AI agent.

eg: Check the code structure and brief about that.

Include the important instructions that affected the implementation.

### 2. Workflow Structure, Advantages & Shortcomings

Professionally describe the workflow structure of your solution.

Include:

- The overall workflow and architecture.
- The main components and their responsibilities.
- How the components communicate with each other.
- The key technical decisions you made.
- The main advantages of your approach.
- The main shortcomings, limitations, or trade-offs.
- What you would improve with additional time.

Keep this section focused on your actual implementation and decisions.

Do not describe hypothetical features or improvements that were not part of
your implemented solution unless clearly identified as future improvements.

### 3. AI Usage

Briefly explain how you used the AI agent during the assessment.

Include:

- How you communicated your requirements and technical direction.
- How you controlled the AI agent's scope.
- Which parts of the implementation you directed or reviewed yourself.
- Any important corrections or redirections you gave to the AI agent.

The purpose of this report is to evaluate your ability to understand the
solution, make technical decisions, and effectively direct an AI coding agent.
